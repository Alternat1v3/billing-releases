# BoltSync downloads

BoltSync is offline-first billing, inventory and accounting software for retail shops in Pakistan. This repository hosts the Windows installers and auto-update files. The source code is private.

**[Download the latest version](https://github.com/Alternat1v3/billing-releases/releases/latest)** · **[tryboltsync.com](https://tryboltsync.com)**

- Sales, purchases, returns and stock, including IMEI tracking for phones
- Day closing, cash and bank books, a double-entry ledger and 20+ reports
- Keeps working offline, and several PCs in one shop can share one database
- Encrypted backups to your PC and Google Drive
- Updates itself when a new version is released

Installed copies check this repository for updates, so please don't download files from anywhere else.
